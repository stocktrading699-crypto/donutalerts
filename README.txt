DonutAlerts - Fabric mod for Minecraft 1.21.5

OPEN IT (keys are changeable in Options > Controls > DonutAlerts):
  K or /donutalerts           main menu
  J or /donutalerts move      move the boxes (drag them, Esc to save)
  L or /bidding               auction menu (auto-picks the item you're holding)
  /bidding stop               stop / clear the auction

BUILD (GitHub builds it for you, nothing to install):
 1. github.com > free account > + > New repository (or open your existing donutalerts repo).
 2. Add file > Upload files. Unzip this zip and drag EVERYTHING inside in (src, .github, build.gradle,
    settings.gradle, gradle.properties). Commit changes.
 3. Actions tab > wait for the green check (~5 min).
 4. Click the run > Artifacts > download DonutAlerts-jar > unzip > put the .jar in Lunar's Fabric mods folder (1.21.5).
